# 🏨 Ascenda Hotel Booking System

## 📌 Overview
This project is a **Hotel Booking Web Application** developed as part of the *Elements of Software Construction* module at **SUTD**, in collaboration with **Ascenda**.  
The system allows users to **search, view, and book hotels** with real-time data from Ascenda’s APIs.  
Built with a **full-stack architecture**, the application ensures scalability, reliability, and a smooth user experience.

---

## ✨ Features
- 🔎 **Search Hotels** – Dynamic search bar with destination images.  
- 🏨 **Hotel Listings** – Displays available hotels with consistent design.  
- 📸 **Hotel Details Page** – Image carousel, thumbnails, progress bars, and detailed information.  
- 🔗 **API Integration** – Connected with Ascenda’s proprietary APIs for live hotel pricing and availability.  
- 🧪 **Testing & Reliability** – Implemented **unit, system, and integration testing** as part of SDLC.  
- 🔒 **Secure & Scalable** – Backend designed for performance and maintainability.  

---

## 🛠️ Tech Stack
- **Frontend:** React.js, HTML, CSS  
- **Backend:** Node.js, Express.js  
- **Database:** MySQL  
- **APIs:** RESTful APIs, Ascenda Proprietary APIs  
- **Design Tools:** Figma  
- **Other:** Git, SDLC practices, Testing Frameworks
